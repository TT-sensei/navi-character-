# NAVI CHARACTER

小学校向けWeb教材で共通利用する6人のナビゲーションキャラクター素材サイトです。

## 方針

- 画像は元データを変更せず、そのまま掲載する
- 管理用IDだけを内部で使用する
- 画面には個人名を表示しない
- HTML / CSS / JavaScriptのみで動作する
- GitHub Pagesで公開できる構成にする

## 管理用ID

| キャラクター | 内部ID |
|---|---|
| キャラクター1 | `riku` |
| キャラクター2 | `sora` |
| キャラクター3 | `kai` |
| キャラクター4 | `saku` |
| キャラクター5 | `tsuki` |

内部IDは教材から画像を呼び出すための識別子です。画面上には表示しません。
