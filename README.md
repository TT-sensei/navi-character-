# navi-character-

小学校向けWeb教材で共通して使う、6人のナビゲーションキャラクターとファンタジー素材の共通素材集です。

通常の学習画面で使うナビキャラ、集合・日常・学習シーン、日常背景、ファンタジー版キャラクター、モンスターなどを、同じ世界観とルールで管理します。

公開カタログ：
https://tt-sensei.github.io/navi-character-/

AIや教材制作では、まず `AI-GUIDE.md`、素材の実在確認には `catalog.json`、教材への組み込み方は `NAVI-USAGE.md` を確認してください。

## この素材集の役割

ナビキャラは教材の主役ではなく、学習を支える案内役です。

問題文・図・答え・入力欄・操作ボタンを最優先し、キャラクターは「始める」「考える」「ヒント」「正解」「再挑戦」「達成」などの意味を補助します。

画像に文字や吹き出しを埋め込まず、メッセージは教材側のHTMLで表示します。キャラクターを大きくしすぎて問題や操作を隠さないことも基本ルールです。

顔、髪型、髪色、服装、体格などの識別要素は勝手に変更しません。特に、かいの丸い黒ぶち眼鏡は必須のアイデンティティです。

## 通常版の素材

主な構成は次のとおりです。

```text
assets/characters/{character-id}/
├── reference.jpeg
├── fullbody/
└── expressions/

assets/web/characters/{character-id}/
├── fullbody/
└── expressions/

assets/groups/
├── daily/
└── learning/

assets/backgrounds/daily/
assets/web/backgrounds/daily/
```

通常版には、共通ポーズ、表情、6人集合、日常シーン、教科別学習シーン、二人組の交流シーン、キャラクターを重ねて使える日常背景などがあります。

Web教材では、Web配信用に用意された `assets/web/` の画像を優先して使います。高画質原本を各教材へコピーして再配布するのではなく、公開カタログで確認した既存パスを参照してください。

## 共通表情

共通表情は、キャラクターIDを変えて同じ意味で利用できるように設計しています。

```text
01-normal-smile
02-happy
03-thinking
04-idea
05-surprised
06-troubled
07-encouraging
08-celebrating
09-frustrated
10-confident
```

開始・正解・ヒント・再挑戦・完了などの共通ポーズも、可能な限り同じファイル名で揃えています。

個別ポーズや集合画像は、`catalog.json` に存在することを確認してから使用してください。

## 日常背景

日常背景はキャラクターを描き込まない「場」の素材です。教室、体育館、図書室、カフェ、まち、公園、校庭、リビング、川沿いなど、通常版ナビキャラを重ねて使える背景を収録しています。

背景の中央や手前にはキャラクターを置ける余白を確保し、問題文や入力欄の可読性を優先します。キャラクターの足元には必要に応じて接地影を加えます。

背景に人物・文字・問題・ボタンを焼き込む使い方はしません。

## ファンタジー素材

ファンタジー部門は、通常教材の飾りではなく、冒険・バトル型教材のための素材シリーズです。

九九ファンタジーバトル、計算バトル、モンスター図鑑などで、

```text
挑戦する → 攻撃する → ダメージを受ける → 必殺技 → クリア
```

という学習体験をつくるために使用します。

通常の国語・算数・理科・社会の説明やヒントでは、まず通常版ナビキャラを使います。

### ファンタジー版のIDENTITY LOCK

ファンタジー版は、通常版6人の衣装・役割を変えた姿です。別人や別キャラクターとして扱いません。

- 顔、髪型、髪色、体格、基本的な印象を維持する
- 2.5〜3頭身、太めで柔らかな輪郭線、明るいソフトセル塗りを維持する
- 武器やエフェクトでキャラクター本体を隠しすぎない
- 役割、武器、衣装を勝手に入れ替えない
- 人間キャラクターをエルフ、獣人などへ変更しない
- 文字、吹き出し、ロゴを画像へ追加しない

主な役割は次のとおりです。

| 通常版 | ファンタジー役 | 固定要素 |
| --- | --- | --- |
| かい | 魔導士 | 水色・紺のローブ、杖、青い結晶、魔導書、黒ぶち眼鏡 |
| そら | 剣士 | 青いジャケット、軽装、片手剣 |
| りく | 忍者 | 濃紺の衣装、クナイ2本、顔を隠さない |
| つき | アーチャー | 橙色の衣装、青いショーツ、弓、矢筒、エルフ化しない |
| なみ | 守護騎士 | 軽い銀色の防具、青い布、丸盾 |
| さく | 僧侶 | 白〜クリーム色、金色の縁取り、癒しの杖 |

## モンスター

モンスターはファンタジー教材の学習体験を補助する、親しみやすいデフォルメ素材です。

怖さや攻撃性を必要以上に強くせず、2.5〜3頭身程度のちびキャラ感、太い輪郭線、明るい色、見分けやすいシルエットを基本とします。

モンスター図鑑、通常敵、中ボス、大ボスなど用途に応じて使用し、教材ごとに同じモンスターを勝手に描き直さないでください。

## AI・教材制作ルール

AIが新しい教材を作る場合は、次の順番を基本にします。

1. `catalog.json` で実在する素材を確認する
2. `AI-GUIDE.md` と `NAVI-USAGE.md` のルールを確認する
3. 既存の画像を優先して参照する
4. Web教材では `assets/web/` のWeb配信用素材を優先する
5. ファイル名やキャラクターIDを推測して新規作成しない
6. キャラクターのIDENTITY LOCKを変更しない
7. 画像へ文字・説明・吹き出しを焼き込まない
8. 教材ごとに画像をコピーして独自版を作らない

新しい共通素材が必要な場合は、既存素材との重複を確認してから、このリポジトリへの追加を検討します。

## 4基盤との関係

TT-senseiの教材共通基盤では、ナビキャラも `edu-assets` と組み合わせて利用します。

| 基盤 | 役割 |
| --- | --- |
| `edu-components` | 動作・ロジック・状態管理 |
| `edu-effects` | UI・CSS・視覚演出 |
| `sounds-recipe-` | サウンド |
| `edu-assets` | バッジ・エレメント・コレクション画像 |
| `navi-character-` | ナビゲーションキャラクター・シーン・ファンタジー素材 |

たとえば学習教材では、`edu-components` が正解を判定し、`edu-effects` がフィードバックを表示し、`sounds-recipe-` が音を鳴らし、`navi-character-` が「よくできた！」などの意味を補助するキャラクターを表示し、`edu-assets` がバッジを表示する、という組み合わせができます。

4基盤・ナビキャラをすべて使う必要はありません。教材の目的に必要なものだけを選びます。

## 開発方針

- 小学校の授業で使いやすいことを優先する
- iPad・タブレットで見やすいことを優先する
- 学習内容と操作をキャラクターが邪魔しないようにする
- 既存素材を再利用し、教材ごとの重複制作を減らす
- 外部フォントや外部画像サービスに依存しない
- 画像の実在性はカタログで確認する
- キャラクターの一貫性を長期的に維持する
